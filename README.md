# Night City Data — offline Excel table viewer (POC)

A React app that builds into **one self-contained `index.html`**. Double-click it and it runs from `file://` — no server, no CDN, no fonts or API calls. All JS, CSS and the mock data are inlined into that single file.

## What it does

- Shows the bundled `data/mock-data.xlsx` (sheets **Roster**, 2,500 rows, and **Gigs**, 600 rows) as a paginated table
- Sheet tabs, search across all columns, click-to-sort headers (asc → desc → off), 25/50/100/250 rows per page, ← / → keys to change page
- **Load .xlsx** button (or drag a file onto the page) opens any other workbook — it's parsed in the browser and never leaves the machine

## Commands

```bash
npm install
npm run build   # → dist/index.html  (the only file you need to ship)
npm run dev     # local dev server with hot reload
npm run mock    # regenerate data/mock-data.xlsx
```

To ship different default data, replace `data/mock-data.xlsx` and run `npm run build`.

## Why it's fast

- **Excel is parsed at build time.** A small Vite plugin (`vite.config.js`) turns `import data from './mock-data.xlsx'` into JSON, so opening the page does no unzipping or XML parsing for the bundled data.
- **Single file** via `vite-plugin-singlefile` — one read from disk, nothing else to load.
- **Only the current page is rendered** (≤ 250 rows in the DOM). Search uses a per-row index built once per sheet; sorting and filtering work on row indices, and `useDeferredValue` keeps typing responsive.
- Runtime `.xlsx` loading uses [`read-excel-file`](https://www.npmjs.com/package/read-excel-file) (small, maintained); it's only exercised when a user picks a file.

## Guaranteed offline

The production build carries a Content-Security-Policy (`default-src 'none'`) that blocks every network request. The only exception is `worker-src blob:`, an in-memory worker the unzip step uses — it never touches the network.

## Layout

```
data/mock-data.xlsx          default dataset (generated by scripts/generate-mock.mjs)
src/App.jsx                  workbook state, sheet tabs, file loading / drag & drop
src/components/DataTable.jsx search, sort, pagination
src/lib/normalize.js         sheet → { columns, types, rows } (shared by build + browser)
vite.config.js               xlsx→JSON plugin, single-file build, offline CSP
```

Limits for this POC: `.xlsx` only (no `.xls`/`.csv`), first non-empty row is treated as the header, formulas show their cached values.
